## Integración local preparada
El selector conserva sus ciudades originales y admite regiones ADM1 diferenciadas procedentes de un módulo estático. Para generar el módulo, ejecutar el importador con una ruta de salida nueva terminada en .js; revisar el resultado y sustituir ui/territory-catalog.js solo con datos reales aprobados. El módulo comienza como null; mientras falte la geometría se mantienen las ciudades existentes. Mostrar atribución junto al selector una vez cargado. Las opciones ADM1 encuadran el mapa mediante extensiones, no delimitan jurídicamente las búsquedas. ADM2/ADM3 y formularios siguen pendientes. No activar catálogo incompleto.
