Pasos para solicitar el servicio

  1. Envíanos por WhatsApp el nombre del cliente, referencia y la ubicación (coordenadas o enlace).
  2. Generamos tu código AD507 y los enlaces (Google Maps, Waze, Uber y aviso de llegada).
  3. Te entregamos el link para compartir + verificación para imprimir.
  4. Listo: el cliente abre su panel con su código y usa los botones.
